# 申请材料核对清单

> **单项材料依个人TUMonline申请显示为准**；RCI 官网页详情是最终权威：https://www.cit.tum.de/en/cit/studies/degree-programs/master-robotics-cognition-intelligence/

## 基本资格

- [ ] 明确报考学期（WiSe/SoSe）并核实最终截止
- [ ] 本科所属学科与 RCI 对照合格（数学/CS/物理/电气/机械/工程及可比）
- [ ] 官方课程 syllabus / Modulhandbuch 可提供
- [ ] 英语和德语的合规证书、上传格式与有效期限
- [ ] 在国外获得本科资格则完成 uni-assist VPD 申请
- [ ] 对适用学历国家，准备 APS 和 GRE/GATE
- [ ] 2025规则下若缺控制课，可接受入学后 ED140014，待校方审核认定

## 文档

- [ ] 官方成绩单 + 必要翻译
- [ ] Curricularanalyse 表（按指引选最佳120 ECTS）
- [ ] 完整课程 syllabus
- [ ] 德语和英语语言证明
- [ ] CV、学校要求的 photo 和 passport
- [ ] 不超过2页且 **申请者独立撰写** 的 Motivation Letter
- [ ] 大约1000词且 **申请者独立撰写** 的 Scientific Essay，引用规范、指定选题
- [ ] 额外证书及申请门户单独指示的材料
- [ ] 截止日前上传全部必需材料、确认系统状态

## 录取后

- [ ] 检查缴费类型/个性化 waiver 资格
- [ ] 医保法定手续和注册/后续原件
- [ ] 房源与当地住址注册
- [ ] 检查TUMonline学籍状态
- [ ] 参加专业 Orientation + CIT matched seminar/practical 安排
