## 开发环境（推荐）

1. 熟练掌握 Linux terminal、Git、CMake、Python、C++17及 Docker、virtualenv/conda。
2. [ROS 2](https://docs.ros.org/en/rolling/) 的节点、消息、服务、Action、`tf2`、`rosbag2`、URDF；实际安装版本与操作系统兼容。
3. [Gazebo](https://gazebosim.org/docs/latest/tutorials/) 物理仿真 + [ros2_control](https://control.ros.org/)；用于硬件在环前仿真。
4. [MoveIt 2](https://moveit.ai/) + [Pinocchio](https://github.com/stack-of-tasks/pinocchio) 或 [Drake](https://drake.mit.edu/) 做运动学/动力学。
5. 视觉：OpenCV、Open3D、GTSAM；深度学习：PyTorch；具身智能：LeRobot。
6. 想走高级仿真/学习可用 [MuJoCo](https://mujoco.readthedocs.io/en/stable/) 或 [Isaac Sim](https://docs.nvidia.com/learning/physical-ai/getting-started-with-isaac-sim/latest/index.html)，根据显卡/项目资源选择。

**版本兼容提醒：**MoveIt 已有 ROS2 Lyrical 2026 LTS 推荐版，同时 Jazzy/Kilted 等仍可用。**不要跨 distro 随便复制 install 命令**，以 [MoveIt 安装矩阵](https://moveit.ai/install-moveit2/source/) 及 ROS 官方文档为准。

## 12周自学学习路线（目标：能申请 robotic perception/learning 实验室）

- **第1–2周：**Linux/ROS2、Python/C++、Git，做一个有 README 的小 ROS2 package。
- **第3–4周：**SE(3)、坐标变换、机器人 FK/IK，使用 RViz 做简单可视化。
- **第5–6周：**OpenCV camera calibration + TUM RGB-D，输出轨迹对齐报告。
- **第7–8周：**PyTorch/机器学习基线与有 reproducibility 的实验报告。
- **第9–10周：**MoveIt2/Gazebo 路径与控制，一个可复现容器。
- **第11周：**阅读选定实验室最近两年论文，复现一个最小结果。
- **第12周：**形成代码/实验/视频 portfolio 和 1页 research proposal。

理论快速补缺：优先线性代数、微分、概率估计、最小二乘、刚体动力学；比一上来搭十几个框架更重要。
