# 08 常见问题（FAQ）与德英中术语

### Q1. Robotics 与 Roboterdynamik 都必须上吗？
不是。对应 A 组6ECTS，只能二选一：IN2067 或 ED160028。

### Q2. 硕士都用英语授课吗？
不是。专业表述为德语+英语，必修大部分列 EN，但是 ED160028 为 DE/EN，ED140014 控制理论补修与一些 H 类选修可能只用德语授课。入学还需按项目要求提供英语和德语能力证明。

### Q3. 2025年之后还要申请前有控制理论5学分吗？
申请前的统一前置条款被2025修订删除，但学历审核如果认为没有达标，入学后必须在硕士中上 ED140014 5ECTS，对应专业自由选修减少5。

### Q4. 2026/27 冬季 Matching 已经结束怎么办？
检查 CIT 官方剩余课程页面，并按要求发邮件给该课负责人。只有满足官方极有限的“学业将因缺必修席位延期 + 主动询问过3个以上剩余名额”才可考虑应急机制，而且2026/27应急窗口为9月，已过。

### Q5. TUMonline 选课后就等于报考试了吗？
不是；很多课程需要独立考试注册。实践/研讨个别例外另看所在学院规定。

### Q6. 2025 Annex 写的课程都每学期开放吗？
不保证。学期栏是法规列出的常规预期开课时段。实际上课请查 TUMonline；持续更新的选修目录以最新官方公布为准。

### Q7. 德语课能算 6 ECTS 跨学科吗？
RCI 专业学习计划强调：作为跨学科选修，德语课程仅从 **C1.2 级** 起可认可。仍需看具体课程和学分是否批准。

### Q8. 入学前能不能先开始硕士论文？
按制度登记和资格要求确定；没注册/没学院认可的公司项目不能直接认成 30ECTS 硕士论文。导师发起论文注册系统后按程序操作。

### Q9. 社区仓库的旧笔记能直接拿来复习吗？
可以作参考，但不能把旧年份的题型、模块 ID、考试范围、讲课教师当作当年信息。材料不得违反课程许可和学生诚信规定。

### Q10. 我可以把学院课程PPT上传到我的 GitHub 吗？
不能默认这样做。Moodle 登录权限不等于公开转载许可；请查课程版权和讲师授权。

## 术语表

| 德文/英文 | 中文 | 用途 |
|---|---|---|
| FPSO / Fachprüfungs- und Studienordnung | 专业考试与学习条例 | 必修/选修/考试限制 |
| APSO / Allgemeine Prüfungs- und Studienordnung | 一般考核与学业条例 | 跨专业通用规定 |
| ECTS | 欧洲学分 | 120 ECTS毕业要求 |
| Studienplan | 课程学习规划 | 推荐进度，不是唯一课程顺序 |
| Modulhandbuch | 模块手册 | 申请课程对照、课程详细要求 |
| Wahlpflicht | 选修必选领域 | 领域满足最低ECTS |
| Pflichtmodul | 必修模块 | 固定毕业条件 |
| Wahlmodul / Wahlbereich | 选修模块 / 模块群 | G/H/I/J |
| Überfachliche Grundlagen | 跨学科基础/素养课程 | J组六学分 |
| WiSe/WS (Wintersemester) | 冬季学期 | 多在10月至3月 |
| SoSe/SS (Sommersemester) | 夏季学期 | 多在4月至9月 |
| Vorprüfungsdokumentation/VPD | 学历预审报告 | uni-assist办理（多数境外学历） |
| APS | 学历审核证明 | 部分国家本科学历申请必备 |
| Eignungsverfahren | 适应性选拔 / 资格审查 | 两阶段录取 |
| Zulassung | 录取许可 | 不等于已完成注册 |
| Immatrikulation | 正式注册 | 完成手续才有在读身份 |
| Rückmeldung | 重新注册（下学期） | 按期限缴费/确认 |
| Prüfungsanmeldung | 考试报名 | 不等于听课报名 |
| Prüfungsabmeldung | 考试退考 | 按考试类型和时间限制 |
| Matching | 研讨/实训课分配 | 非普通TUMonline选课 |
| Masterpraktikum | 硕士实训项目 | IN2106，10学分 |
| Masterseminar | 硕士研讨课 | IN2107，5学分 |
| Wissenschaftliche Ausarbeitung | 科学论文 / 研究报告 | 研究工作与诚信评审 |
| HiWi / studentische Hilfskraft | 学生助理 | 通常有偿，不等于课程学分 |
| Garching-Forschungszentrum | Garching 校园U6站 | 通勤地点 |

**一切冲突按入学批次FPSO及个性化学籍记录处理。**
