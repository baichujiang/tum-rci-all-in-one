# 01 申请、资格审查、材料与录取

**原始权威：**[RCI 官方申请页](https://www.cit.tum.de/en/cit/studies/degree-programs/master-robotics-cognition-intelligence/) · [2025 FPSO修订](https://www.tum.de/studium/im-studium/das-studium-organisieren/satzungen-ordnungen?tx_in2tumstatutedatabase_pi1%5Baction%5D=download&tx_in2tumstatutedatabase_pi1%5Bcontroller%5D=Statute&tx_in2tumstatutedatabase_pi1%5BfileId%5D=P008777873) · [TUM 申请门户](https://campus.tum.de/)

## 申请日期

- 冬季入学：**2月1日—5月31日**；需要签证者 TUM 建议尽量于 **3月31日前**提交。
- 夏季入学：**10月1日—11月30日**；需要签证者建议 **10月31日前**提交。
- 以上提前日期是**建议**；以官网公布的最终截止为准，不能晚交材料；TUMonline 的实际可操作时间及材料状态最重要。
- 截至 2026-10-11，下一轮是 **2027年夏季学期申请，2026-11-30 截止**。

## 什么本科学历可能符合？

官方列 Informatik、Mathematik、Physik、Elektrotechnik & Informationstechnik、Maschinenwesen、Engineering Science 或可比学位。**可比性需学校逐案审核**，不是名字类似就保证录取。成绩按 *本人申报的最好的120 ECTS* 进行评价，必须按照官网 Curricularanalyse 模板填写；为跨学校学分制度转换要阅读官方FAQ。

## 必备 / 条件性材料

- [ ] `TUMonline` 完整网上申请（VPD ≠ 正式申请）
- [ ] Tabellarischer Lebenslauf 简历
- [ ] Motivation Letter / Begründungsschreiben，**最多两页 A4**，**本人独立完成**
- [ ] 选择指定课题之一的科学 Essay，**约1000词，文献可核验、必须独立完成**；官网明确禁止他人帮助和未经授权辅助工具。请勿用生成式工具代写
- [ ] 本科学校官方成绩单及需要时的正式译文
- [ ] 本科专业课详细 Curriculum/Syllabus 或模块手册（特别重要）
- [ ] Curricularanalyse 表格转 PDF（官网提供样表）
- [ ] 德语 + 英语能力证明（具体可接受证书在 TUM 统一语言规定）
- [ ] 条件性：VPD from uni-assist，适用于多数在德国以外取得学历者
- [ ] 条件性：APS，在中国、印度、越南取得相关本科学历者查官方条款；一些地区可豁免，不能一概而论
- [ ] 条件性：GRE/GATE，根据完成前置学历的国家、当年政策而定
- [ ] 护照/照片；其他校方要求的实习、证书或附加文件
- [ ] 录取后：医保、正式毕业证、某些原件或认证副本等注册材料

## GRE 的具体官方最低门槛

对在 **中国、孟加拉国、印度、伊朗、巴基斯坦**完成符合条件的高校学位者，RCI 申请网页要求 GRE General：

| 分项 | 官方最低值 |
|---|---|
| Quantitative Reasoning | **164** |
| Analytical Writing | **4.0** |
| Verbal Reasoning | 无最低值 |
| Institution Code | 7806 |
| Department | 5199 |

**印度 GATE 成绩**可能作为 GRE 的替代。请注意这是官方按“学位取得国家”设置的筛选，不应该只按国籍推定；及早向 TUM 确认不适用的例外。

## 科学 Essay 题目（来自专业官网）

1. Bio-inspired robots - a distraction from proper engineering?
2. Is unregulated AI (Artificial Intelligence) research a good idea?
3. Autonomous Cars: What problems need to be solved to get from assisted driving to fully autonomous driving?

**重要诚信警示：**官方明确要求 Essay 与 Motivation Letter 是申请者自己、在没有他人帮助的情况下独立完成。此仓库只提供选题、来源与写作要求，不代拟这两份材料。

## 录取程序

1. 第一阶段：本科课程匹配度 + 最佳120ECTS 学业成绩 + 科学论文 + Motivation。
2. 结果可能直接录取、直接拒绝或进入第二阶段面试。
3. 第二阶段：约 **20–30分钟** 面试；最晚一周前收到电子邮件邀请。
4. 录取结果后按 TUMonline 完成注册与缴费，审核入学前缺失材料。
5. 若推迟入学：**不能直接无条件转入下学期**。官方说明需在下一学期窗口**重新申请**；若相同专业已获录取且按要求再次提交材料，通常免重新评审适应性。

## 2025 年控制理论前置课的重要变化

2024 FPSO 对申请期已具备控制理论5ECTS有要求；2025.02.11 修订 **删除了该申请硬性前置**（对 2025/26 冬季及之后入学者）。但如果审查认为此前未获得相当于 **ED140014 Regelungstechnik** 的控制理论能力，则必须在硕士课程中完成该 5 ECTS 学习，其学分从专业选修里相应扣减。不可解读为“现在完全不需控制理论”。
