## 选择研究方向的逻辑

1. **Perception / SLAM**：IN2228、IN2354、IN2404；读 TUM RGB-D 和 TUM VI 的官方 Benchmark；从定位准确度、闭环检测、传感器标定做实验。
2. **Manipulation / Planning**：IN2067、IN2138；ROS2、MoveIt2、Pinocchio/Drake/MuJoCo；复现路径规划和控制栈。
3. **Robot Learning / Embodied AI**：IN2064、IN2406、IN2346；PyTorch+ROS2+simulation；研究 imitation learning、reward design、VLA。
4. **Control / Dynamics / Humanoids**：ED160028、IN2061、EI7210；最优控制、状态估计、鲁棒控制和实机安全。
5. **Human Robot Interaction / Wearable**：IN2107/IN2106 HRI专题；人因评估、感知、安全和可穿戴传感器。
6. **Autonomous Driving**：Robot Motion Planning/CPS/视觉，AVS + Foundation models。

## 寻找 HiWi / Projekt / Guided Research / Master Thesis

- 短名单：3–8个匹配团队，按兴趣与论文排序；读每组最近2–3篇代表论文和项目介绍。
- 发学术邮件：研究兴趣、你可以带来的技能、既往可展示的 GitHub/项目、可以开始的日期，附**简历、成绩及作品清单**（如导师要求）。
- 区分**受薪 HiWi（学生助理）**、**课程可记学分的 IN2169 Guided Research**、**IN2106 Practical**、**30 ECTS Master's Thesis**。这四个身份的付薪、学分和审批方式不同，不能自动互抵。
- 面试/邮件中主动问：导师资格、具体项目、code/data licence、是否能在 RCI 认可为论文、论文开始前需满足什么成绩要求。
- 若为公司硕士论文，必须确保**TUM有适当学术指导与书面审批**，保密IP、公开论文、期限等要先谈妥。

## 硕士论文最关键流程

- 法定模块：**IN2320 Master's Thesis，30 ECTS**；常见执行期 **6个月**，官方程序优先。
- 官方 RCI 专业页面有论文相关说明；通过 [CIT Thesis Portal](https://portal.cit.tum.de/de/Theses/) 完成登记，通常由导师/指导单位发起，学生确认后进入学籍流程；提交仍需按当时系统要求。
- 不要依赖一般 Informatics 网页覆盖本专业所有步骤；RCI 与其他 IT 硕士的学籍归属有细微差异，应征询 `rci@tum.de`。
- 产出标准实践：书面 proposal → 研究设计 → baseline → 实验记录/指标 → 技术报告 → 完整LaTeX论文、引文与演示。

## 实验复现模板

1. 把论文和公式拆分：数据、评价指标、baseline、主要贡献与训练/控制流程。
2. 固定 Docker/conda 环境 + ROS distro 版本 + commit hash + random seed。
3. 先用最小数据集跑通读取、可视化、评价（例如 TUM RGB-D trajectories）。
4. 将实验日志、参数、硬件版本写入 Git（隐私/许可受限内容除外）。
5. 统计平均值、方差、种子，生成可复现实验说明，不把一次模拟成功当成可靠实机结果。
